Bienvenido a este curso completo de **Swift y SwiftUI** en español, diseñado para llevarte desde cero hasta publicar tu primera app en la App Store. 🚀

---

## 🎯 ¿Para quién es este curso?

- Personas sin experiencia previa en programación Swift
- Desarrolladores de otros lenguajes que quieren aprender Swift
- Personas con ganas de crear apps para iPhone, iPad y Mac

## 🛠️ Requisitos

| Herramienta | Descripción |
|---|---|
| 💻 **Mac con Apple Silicon** | MacBook Air M1/M2/M3 o similar |
| 📱 **iPhone** | Para probar tus apps en dispositivo real |
| 🖥️ **Xcode** | IDE oficial de Apple (gratis en Mac App Store) |
| 🎮 **Swift Playgrounds** | Para ejercicios interactivos (Mac y iPad) |
| 👤 **Apple ID** | Necesario para desarrollo (cuenta gratuita) |

## 📝 Cómo usar este curso

1. Sigue los módulos **en orden**
2. **No te saltes** los ejercicios de Swift Playgrounds
3. Escribe el código **tú mismo**, no solo lo leas
4. Construye los **mini proyectos** de cada módulo
5. Si te atascas, consulta los recursos externos
